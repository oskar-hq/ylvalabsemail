    Durchlass für die Agents

    Grok und Claude rufen das OS von ihren Servern aus auf. Vor der App steht Cloudflare Access mit Einmal-Code; daran kommen sie nicht vorbei. Darum einmalig drei Pfade freigeben. Die Anmeldung selbst (wer verbinden darf) schützt weiter das OS.

    {% if check %}

    {{ '✓ ' if check.ok else '' }}{{ check.text }} Geprüft {{ check.am|kurzdatum }}

    {% endif %}
    So geht es in Cloudflare (2 Minuten)
    1. Auf one.dash.cloudflare.com anmelden → Access → Applications → Add an application → Self-hosted.
    2. Name „Ylva OS Agents“. Bei Application domain drei Einträge mit der Domain der App und je einem Pfad: mcp, oauth, .well-known.
    3. Bei Policies eine Regel anlegen: Action Bypass, Include Everyone. Speichern.
    4. Hier auf „Jetzt prüfen“ tippen. Die übrige App bleibt hinter dem Einmal-Code.

    In Grok verbinden

    Für jeden Bot einen eigenen Connector mit seiner Adresse. So weiß das OS, welcher Bot was tut.

    1. In Grok die Einstellungen → Connectors öffnen → Connector hinzufügen (eigener / Custom MCP).
    2. Name „Ylva OS Ops“ (usw.), Adresse von unten einfügen, speichern. Grok öffnet die Anmeldung des OS.
    3. Dort mit deinem OS-Konto anmelden und auf Verbinden tippen. Der Agent ist schon vorausgewählt.
    4. Im jeweiligen Bot den Connector einschalten und den Umzugs-Prompt aus Schritt 5 einfügen.
